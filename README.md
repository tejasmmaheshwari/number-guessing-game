# Number Guessing Game

## Project Overview
A Python-based number guessing game in which players try to guess a randomly generated number. The application provides hints to guide the player and includes a graphical user interface for interactive gameplay.

## Technologies Used
- Python
- Tkinter for the graphical user interface
- Python's `random` module for generating random numbers

## Features
- Generates a random number between 1 and 100
- Provides hints to help the player guess the number
- Tracks the number of attempts
- Supports multiple rounds of gameplay
- Offers an interactive graphical interface

## Project Structure
- `Num_guess_game.py` — main game logic
- `num_game_gui.py` — graphical user interface
- `README.md` — project documentation

## Setup Instructions

### Prerequisites
Install Python 3.x on your computer.

### Run the Application
Clone or download this repository and open a terminal in the project folder.

To run the command-line game:

```bash
python Num_guess_game.py
```

To launch the graphical interface:

```bash
python num_game_gui.py
```

Tkinter is included with many standard Python installations. Ensure it is available in your Python environment.
